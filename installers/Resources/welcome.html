Welcome to the Wild Jag Plugins installer

On the next screen, use the checkboxes to choose which plugins to install, and within each plugin which formats (Audio Unit, VST3, Standalone App):

  • Caverns - reverb/delay
  • Damage - fuzz/distortion
  • Corrosion - lo-fi drive
  • Flux - analog phase shifter

You'll also be asked whether to install for all users of this Mac (/Library/Audio/Plug-Ins, /Applications - requires an administrator password) or just for you (~/Library/Audio/Plug-Ins, ~/Applications - no password needed). Both are locations every AU/VST3 host scans.

Restart your DAW (or run AU validation) after installing so it picks up the new plugins.
