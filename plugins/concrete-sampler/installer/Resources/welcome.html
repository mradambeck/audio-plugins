Welcome to the Concrete installer

On the next screen, choose which formats to install:

  • Audio Unit (AU) - Concrete.component
  • VST3 - Concrete.vst3
  • Standalone App - Concrete.app

You'll also be asked whether to install for all users of this Mac (/Library/Audio/Plug-Ins, /Applications - requires an administrator password) or just for you (~/Library/Audio/Plug-Ins, ~/Applications - no password needed). Both are locations every AU/VST3 host scans.

By default, this plugin sends an anonymous ping when it opens and when you load a factory preset (plugin name, version, OS - never audio, project data, or anything personally identifying). On the next screen, check "Opt out of anonymous usage analytics" to disable this.

Restart your DAW (or run AU validation) after installing so it picks up the plugin.
